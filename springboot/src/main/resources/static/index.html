Project Overview

Shopizer is a comprehensive e-commerce platform built using component-based software engineering principles. The system is designed with a layered architecture consisting of Presentation Layer, Business Layer, and Data Layer. It implements Spring Boot for the main application framework with OSGi bundle support for modular deployment. The platform provides complete functionality for product catalog management, shopping cart operations, order processing, payment handling, merchant store management, and customer account management.

Catalog Module

  • FR-001 Manage products (CRUD)
  • FR-002 Manage categories (CRUD)
  • FR-003 Search products by keyword
  • FR-004 Browse products by category
  • FR-005 Track product stock levels

Cart Module

  • FR-006 Manage cart items (Add, View, Update, Remove)
  • FR-007 Calculate cart total automatically
  • FR-008 Validate product availability
  • FR-009 Persist cart for logged-in customers

Order Module

  • FR-010 Place orders from cart
  • FR-011 Generate unique order reference ID
  • FR-012 View order history
  • FR-013 Track and update order status
  • FR-014 Cancel pending orders

Merchant Module

  • FR-015 Merchant register and login
  • FR-016 Manage store details (CRUD)
  • FR-017 Manage inventory
  • FR-018 View sales reports and analytics

Payment Module

  • FR-019 Process payment for orders
  • FR-020 Support multiple payment methods
  • FR-022 Verify and record transactions
  • FR-023 View payment history

Customer Module

  • FR-024 Register new account
  • FR-025 Login and logout
  • FR-026 Manage profile (View, Update)
  • FR-027 Manage addresses (CRUD)
