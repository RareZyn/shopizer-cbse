🏗️ OSGI Architecture

This version of Shopizer is built using the OSGI (Open Services Gateway Initiative) framework with Apache Felix. The application is decomposed into independent, dynamically loadable bundles that can be installed, started, stopped, and updated at runtime without requiring a system restart.

🔌 Dynamic Modularity

Each module (Catalog, Cart, Order, etc.) is an independent OSGI bundle that can be updated without affecting other modules.

🔄 Service Registry

Bundles communicate through OSGI's service registry, enabling loose coupling and dynamic service discovery.

⚡ Hot Deployment

Bundles can be installed, started, stopped, and updated at runtime without restarting the application.

🛡️ Version Management

Multiple versions of the same service can coexist, allowing for seamless upgrades and rollbacks.

Project Overview

Shopizer OSGI is a comprehensive e-commerce platform demonstrating component-based software engineering through OSGI's dynamic module system. The architecture consists of independent bundles for catalog management, shopping cart, order processing, customer management, and merchant operations. Each bundle is self-contained with its own lifecycle, dependencies, and service exports. The REST API module uses embedded Jetty server to expose HTTP endpoints, while the Common module provides shared utilities and data models. This modular approach enables independent development, testing, and deployment of each component while maintaining a cohesive system.
